# QAT Toolkit Repository

## 1. Repository Overview

This Quality Assurance Testing (QAT) toolkit contains documentation and implementation artifacts for testing an AI-generated web application: **Kara David Birthday Wishnote App**.

### Repository Contents

- **Part A — `Readme.md`:** This README document, containing the test case for the AI-generated web application.
- **Part B — `webapp-generation-prompt.txt`:** The AI prompt used to create the test web application.
- **Part C — PHP web application:** The single-file PHP web application generated by AI.

**Additional file reference:** `textcase.txt`

## 2. Test Case Documentation

| Attribute | Details |
|---|---|
| **Test Case ID** | `TC-DataEntry-001` |
| **Test Case Title** | Data Entry - Valid |
| **Test Case Description** | Functional testing of the Data Entry page with backend validation using MySQL queries. |
| **Preconditions** | The Kara David Birthday Wishnote App is installed locally, and the MySQL database is pre-populated for comparison. The Data Entry page is accessed in the latest Chrome or Firefox browser. |
| **Test Data** | Five (5) valid entries containing First Name, Last Name, Government Position, and Location, each within its maximum character limit. |
| **Status** | **Failed** |

## 3. Test Steps and Results

The following table consolidates the test actions, expected outcomes, and actual outcomes recorded for steps **a** through **i**.

| Step | Action | Expected Result | Actual Result |
|---|---|---|---|
| **a** | Verify that the form contains labels in the proper order and that the text boxes are writable. | The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable. | The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable. |
| **b** | Verify the **Send Wish Note** button. | The **Send Wish Note** button changes color on hover and is not disabled. | The **Send Wish Note** button changes color on hover and is not disabled. |
| **c** | Enter test data in the respective fields. | The respective fields accept valid test data. | The respective fields accept valid test data. |
| **d** | Click the **Send Wish Note** button and verify that the modal appears. | A modal titled **Verify Target Data** appears. | A modal titled **Verify Target Data** appeared. |
| **e** | Verify that the modal contains the same entries as the test data. | The modal shows the same First Name, Last Name, Government Position, and Location that were entered. | The modal showed the same entry as the test data. |
| **f** | Click the **Cancel** button. | The modal closes, and the form data remains on the page. | The modal closed, and the form data remained. |
| **g** | Click **Send Wish Note** again, then click **Confirm and Send** in the modal. | The modal appears again, and clicking **Confirm & Send** submits the form. | The modal appeared again, and clicking **Confirm & Send** submitted the form. |
| **h** | Verify that a successful-entry message appears on the Data Entry page. | The message **"Success! The wish note has been sent."** appears above the form. | The message **"Success! The wish note has been sent."** appeared above the form. |
| **i** | Verify that the test data appears in the database. | All five entries appear in the `main_corrupt_politicians` table, with `FirstName`, `LastName`, `GovPosition`, and `Location` saved. | Query executed: `SELECT * FROM main_corrupt_politicians;`. The five entries appear in the table, but the `Location` column is `NULL` for all rows because the `INSERT` statement omits `Location`. |

## 4. Test Outcome and Observations

The test case status is **Failed**. The form validation, modal workflow, and success-message checks were recorded as successful. However, the database verification identified a data-persistence defect: the `Location` column is `NULL` for all five inserted rows because the SQL `INSERT` statement omits that column.
